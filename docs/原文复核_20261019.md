# 首批生态证据原文复核记录

日期：2026-10-19。对应版本：0.2.11。

本轮读取 **4 篇论文全文**，逐条对照 **45 条目录关联记录（43 个不同 ECOTOX 结果编号）**；其中 **26 条核心字段与原文一致、16 条核对后保留限定条件、3 条派生 NOEC 排除**。同一原始结果可能关联多个目录实体，不能把45条当成45个独立实验。

另查了2篇原始论文的作者摘要，**11条只完成摘要支持字段的核对，10条NOEC在摘要中没有数值，仍待全文**。对全体新增记录的原始注释做了来源线索扫描，另有2条提到QSAR的记录暂缓：这不证明它们就是预测值，需回查原文。共新增68条复核决定，涉及21个目录实体。

原始归档仍为 **22,448 条**；默认可用集合为 **22,443 条**，另有 **3条排除、2条暂缓**。目录覆盖仍为382 / 1,216，暴露记录仍为0。这里的“可用”表示未被本轮复核排除或暂缓，**不表示剩余记录都已逐篇核实**。

## 核对范围与剩余限制

全文复核逐项记录了源文位置、所读文件SHA256、物种、生命阶段、具体响应、时长、数值、限定符、单位和浓度依据。部分字段仍有歧义的，明确列出未解决事项。没有独立重算所有剂量反应模型、统计检验或原始个体数据，也没有完成全面的研究偏倚/质量评级。原文数值一致不证明研究设计完善。

化学身份核对仍与文献核对分开。所有新增记录的身份确认状态仍为0；复核不自动修改目录实物身份、结构、采购或已测标记。材料、混合物、酸盐形式不凭名称自动互换。

既有6PPD-醌的3条原文核对记录仍保留。加上本轮42条一致或带条件核对记录，目前共有45条带全文核对标签的目录关联记录；其中16条明确带有限制，并非全部字段无条件通过。其余大量记录仍为原文待复核。

## 程序与追溯

- 新增只追加的复核事件表，导入的原始`evidence`与来源数据均不改写。可用视图过滤排除/暂缓记录；页面、目录计数、工作流和证据筛查采用同一集合。
- 页面显示全文核对、带限定核对、摘要字段核对及原文待复核状态。排除/暂缓记录另列，保留理由和原文位置。
- 完整证据CSV含原始值、原始介质及`review_decision/review_json`，因此归档导出条数可能高于页面可用条数。复核介质的显示覆盖会注明原始介质，不覆盖原始库值。
- `inputs/literature_review_20261019.json`可重放本批复核；每条决定绑定原始记录摘要，记录若变化则拒绝沿用。重复应用不加倍，冲突和中途错误回滚，不覆盖复核历史。
- 本轮不包含付费模型调用，不新增毒性预测，不合并不同端点、物种或时长，不生成环境风险排名。

可复制运行：`python -m ec_agent.cli import-evidence-reviews inputs/literature_review_20261019.json`。完整后台流程会在导入原始文献数据包后应用这批复核。
