# 0.2.4 目录多选筛选

日期：2026-10-19。

## 更新内容

- 一级类别、采购标记、已测标记和结构状态改为带复选框的下拉框，可连续勾选，无需按 Ctrl。
- 同一筛选内取并集，不同筛选之间取交集。清空某一筛选表示不限；二选项同时勾选包含两种状态。
- 显示已选数量，悬停可查看选项名称；类别右侧数量为全库分类数量。
- 修改筛选回到第一页，翻页保留勾选。支持单项清空、全部重置、Escape 关闭和点击外部关闭。
- 后台使用重复查询参数传递多个值，以绑定参数执行查询，并保留原有单值调用兼容。
- 仅修改查询方式，无新增模型调用或科学判断规则。

## 验证结果

自动化回归 **74 项通过、0 失败、0 跳过**。本次新增 10 项用例覆盖类别并集与去重、单值兼容、空选、参数绑定、跨筛选交集、翻页稳定性、三组二选项、既有结构簇/官能团限定、多值 HTTP 查询和无效选项返回 400。

Microsoft Edge 浏览器检查覆盖连续多选、组合筛选、结果数量、翻页与筛选后回到第一页、单项清空、无匹配结果、全部重置、关闭下拉框及 390 像素宽度布局。目录多选不调用模型；研究问答与固定分析页面可正常切换。

完整回归中的模型测试使用本地模拟服务；本轮未请求真实付费模型。桌面更新保留已有模型配置、Python 环境及数据库；数据库仍为 1,216 个实体。
