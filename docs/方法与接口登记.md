# 方法与接口登记

本表依据本次实际检查的项目源码。科学参数沿用既有项目；方法来源链接沿用2026-10-18调研记录，不将代码测试等同于外部科学验证。

| 工具 | 输入 | 输出/方法 | 当前边界与验证 |
|---|---|---|---|
| catalog_search | 名称、CAS或实体ID | 全目录总匹配数与前12项 | 不按47个候选限制；多匹配停止选择 |
| entity_structure_and_evidence | 精确实体ID | 身份状态、来源、候选、结构及生态记录 | 匹配不等于确认；只读 |
| parse_catalog_structure | 精确实体ID | 从选定SMILES解析，描述符、InChIKey及缓存版本 | 不接受模型提供新结构；核对标识一致性 |
| detect_functional_groups | 精确实体ID | 完整结构的现有17条SMARTS及芳香原子特征 | 规则1.2；有限片段库；不是毒性分类；硝基反例回归检查 |
| find_similar_entities | 精确实体ID、返回数 | Morgan/Tanimoto；半径2、2048位、保留手性 | 检查当前母体与缓存一致；相似性不是毒性等效 |
| inspect_structure_clusters | 精确实体ID、预设距离 | 读取已有Butina簇及参数 | 核查参数、版本和输入摘要；历史值标注，不重聚类 |
| screen_ecological_evidence | 精确实体ID | 证据、单位、限定符、介质、类群、时长、来源及前提缺口 | EPA基准与PNEC/LC50/EC50不互换；当前无暴露，不做综合排名 |

Agent只通过上层 `run_research_workflow` 使用这些工具。参数以本地登记文件为准，不能通过自然语言修改方法。

## 科学方法原始依据

- 圆形指纹：[Rogers与Hahn，2010](https://doi.org/10.1021/ci100050t)；[RDKit实现](https://www.rdkit.org/docs/source/rdkit.Chem.rdFingerprintGenerator.html)。RDKit实现与原始商业实现不宣称逐位相同。
- 聚类：[Butina，1999](https://doi.org/10.1021/ci9803381)；[RDKit实现](https://www.rdkit.org/docs/source/rdkit.ML.Cluster.Butina.html)。原论文采用Daylight指纹，本项目使用Morgan；阈值不是毒性标准。
- 官能团：当前使用项目原有SMARTS 1.2，不将其称为已完整复现Ertl/EFGs。每条规则与外部文献定义的逐项校准仍是后续工作。
- [Ertl，2017](https://doi.org/10.1186/s13321-017-0225-z)、[EFGs，2025](https://doi.org/10.1021/acs.jcim.4c02268)是补充候选，本次未接入。

## 仍待研究者决定/验证

母体及盐型策略、各类污染物的适用性、官能团定义完整性、相似性参数敏感性、已有生态证据的类型、单位与来源核查。不得由Agent自动填充结论或阈值。

规则 1.2 的硝基模式采用 RDKit 官方 Functional_Group_Hierarchy.txt 的 Nitro 项；来源文件与许可证保留在 third_party/。规则的 42 个正反例与边界样例、待人工审阅事项见 [官能团规则校核](官能团规则校核.md)。
