# 0.2.3 研究问答界面更新与验证

日期：2026-10-19。

## 更新内容

- 新增对话侧栏、欢迎页、底部输入框及 6 个推荐问法，覆盖身份核查、官能团、结构相似物、生态证据、同名定位和资料缺口。
- 推荐问法支持分类和点击填入。实体选择、后续追问和错误重填同样只填入输入框，不自动发送，不额外调用模型。
- 保留用户问题与助手回答，支持复制回答、导出单轮记录、导出对话、切换最近对话和清除本机历史。
- 回答中分别呈现资料缺口、来源与实际工具记录。等待状态仅显示请求等待时长，不模拟模型思考或工具进度。
- 当前研究对象显示实体编号、名称和 CAS。后续问题可携带已定位的实体上下文；后台重新核验编号是否存在，不把定位等同于身份确认。无效上下文在创建 Agent 前停止。
- 记录保存在本机浏览器，最多保存 12 段对话及每段最近 40 条消息。历史保存显示内容和调用摘要，不保存 API Key；完整分析文件仍位于项目 outputs/analyses。
- 未新增毒性模型、科学阈值、环境暴露数据或综合风险排名。

## 验证结果

自动化回归 **64 项通过、0 失败、0 跳过**。新增检查覆盖静态脚本和样式的交付、上下文实体校验，以及无效上下文在模型调用前被拒绝。

Microsoft Edge 浏览器检查通过：

- 6 个推荐问法可分类和填入；点击推荐、后续追问、实体选择或错误重填均不自动发送请求。
- Enter 发送、Shift+Enter 换行；中文输入组合期间不触发发送。
- 独立问候走本地帮助；真实工具链通过本地模拟接口执行。
- 刷新后恢复对话与草稿，不重新发送旧问题；继续追问携带已定位的实体编号。
- 同名候选供用户选择，选择前清除旧对象上下文；选择后仍需明确发送。
- 复制与对话导出入口正常；浏览器历史和导出数据不包含测试用模型 Key。
- 接口失败保留前面消息并显示错误编号；模型返回的 HTML 作为文字显示，不执行脚本。
- 桌面与 390 像素宽度布局检查完成；无页面脚本异常，移动端设置按钮未被截断。

对话界面测试使用已运行的本地结构工具结果、模拟模型及请求替身，未调用真实付费服务。用户已有模型配置、数据库及 Python 环境在桌面更新中保留。
