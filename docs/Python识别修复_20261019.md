# Python 解释器识别修复

本机启动器登记的是 `D:\python\python.exe`（Python 3.14.0、64位），普通 `python` 命令指向 Windows Store 别名。此前交付脚本只查启动器的 3.12 和普通命令，遗漏本机已有但未登记的 Python 3.12.14。

安装脚本增加了对当前用户已有 Codex Python 运行环境的检查。只有确认为 Python 3.12、64位才使用它创建项目环境，不会改变原运行环境。找不到时列出启动器版本，解释版本要求；没有取消版本限制。师兄电脑若没有可用的 3.12，仍需安装对应版本。

实际检查通过：本机发现现有 3.12；模拟找不到备用路径时，退出并列出已有 3.14。两种检查均未创建环境、安装依赖或改动数据库。此次未重新安装完整环境，也未验证 Python 3.14 的依赖兼容性。
