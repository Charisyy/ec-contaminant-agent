# 当前版本检查与改进清单

日期：2026-10-19。检查范围：本地源码、现有测试、Windows 桌面启动和 Microsoft Edge 页面交互。没有重新开展论文调研，没有调用真实付费模型，也没有改变目录数据库。

## 本次修复

| 问题 | 已确认的行为与修复 |
|---|---|
| 实体详情串页 | 人为延迟第一次响应，确认它会覆盖后来打开的实体。现在只接受最后一次打开操作对应的结果，关闭详情也使未完成的旧响应失效。 |
| 连接状态不恢复 | 模拟连接中断后恢复，原先页眉仍显示断线。现在成功取得后续请求结果时恢复连接标记，失败目录不继续展示旧查询结果。 |
| 快速连续翻页 | 原先请求尚未返回就能连续修改页码。现在加载中禁用翻页，并采用后台实际返回的页码。 |
| 对话保留数量不一致 | 连续产生 13 段对话时，页面内存原先保留超过 12 段，浏览器持久保存仅保留 12 段。现在两者同步裁剪，连同过期的单轮完整结果缓存一并释放。 |
| 历史片段与当前规则难区分 | 详情明确显示“历史缓存”，并说明点击片段筛选使用同一历史缓存；当前规则计算仍通过固定分析流程完成。 |
| 导出范围不明确 | 顶部改为“导出全量目录”，提示不受当前筛选影响。尚未新增筛选结果导出。 |

## 建议实施顺序

当前版本范围为目录检索、身份与结构核查、官能团分析、结构相似性与聚类，以及已有生态证据整理。以下待办仅围绕该范围安排。

0.2.7 已建立 42 个规则样例和七类离线流程基线，采用 RDKit 官方 Nitro 模式修正硝酸酯误计；证据表已补全对象、介质和时长。规则定义仍需研究者审阅，真实模型尚未执行验收。参见 [官能团规则校核](官能团规则校核.md)和[模型验收清单](模型验收清单.md)。

| 优先级 | 待做事项 | 原因与验收条件 |
|---|---|---|
| 首先 | 真实模型端到端验收 | 当前连接测试只能证明基础请求成功，本地模拟测试也不能代表每家真实服务。使用选定服务分别验收唯一实体、多个候选、缺结构、缺生态证据及服务失败；核对真实工具执行、引用与中文结论。需要单独安排真实请求，本轮未执行。 |
| 首先 | 校准官能团定义与结构处理策略 | 当前 17 条规则属于项目有限片段库；来源登记明确尚未完整复现 Ertl/EFGs。逐条登记定义和文献依据，建立正反例及盐型、多片段、芳香性边界样例；由研究者审阅规则和母体策略。只比较同一版本的统计，不由 Agent 自行设规则。 |
| 随后 | 筛选结果导出与批量固定分析 | 多选目前仅作用于目录列表。建议导出时保留筛选条件、数量、实体编号及时间；批量执行仍采用已有三条固定流程，逐实体保存失败与跳过原因，不增加综合风险分数。 |
| 随后 | 把科研结果整理为更易审阅的报告 | 现在提供 JSON、来源和工具记录，但长篇模型回答仍需人工审阅。增加简明结果表，逐项关联实体、结构/端点、来源和方法版本；明确代码校验仅覆盖流程、标识和来源范围，不等于逐句科学结论已经证实。 |
| 交付前 | 在另一台 Windows 电脑验收安装与升级 | 当前已验证本机环境自动切换和启动；仍需在没有现成项目环境的电脑上验证首次安装、中文路径、停止/重启、升级保留数据库与配置、备份和恢复。免安装启动方案可在依赖和许可核查后再选。 |

“首先”表示继续研究工作前值得优先解决的事项，不表示当前目录查询或固定计算不可用。无需为了改进界面就增加更多 Agent；现有一个 Agent 调用受约束的固定流程可以继续保留。

## 本轮验证的实际含义

- 已复现详情响应覆盖、断线状态不恢复、页面对话超过保留上限，再检查修复后的行为。
- 定向浏览器检查覆盖翻页锁定、结果恢复、历史缓存说明、导出范围、13 段对话后的裁剪及刷新一致性。
- 同时复查目录多选和研究问答交互；模型相关浏览器路径使用本地帮助或请求替身。
- 0.2.7 完整回归报告为 117 项自动化用例，其中新增 42 个规则样例和 1 个覆盖检查；浏览器定向检查与未执行的真实模型清单不混入该数量。
- 本轮结果不证明真实付费服务已完成验收、自然语言科学结论全部正确。
