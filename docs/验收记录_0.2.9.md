# 0.2.9 目录状态与来源契约修复

日期：2026-10-19。

## 当前行为

- 多候选和未找到对象时，回复、候选及实体列表来自实际目录结果。模型解释格式不可用或后续解释中断时，已有目录状态仍可展示；没有明确实体时没有实体级科学结论。
- 工具提供稳定的来源编号。模型只选择编号，程序从本轮实际来源组装完整 URL，减少自由生成链接造成的校验问题。来源编号与原始 URL 的映射由程序建立，不由模型指定。
- 拒绝未知编号、属于其他实体的来源和正文中的越界 URL。内部模型输出改用来源编号，对外结果仍保留完整来源链接，既有导出与对话历史兼容。
- 模型服务在工具执行前失败时仍报错；已有工具结果但解释不合格时保留明确标注的工具整理。不放宽科学权限，不新增自动模型重试。

## 验证与限度

完整回归 130 项通过，0 失败、0 跳过。新增八项来源契约与目录状态测试，覆盖稳定引用、编号解析与去重、无效编号、跨实体来源、正文链接、工具来源登记及两种目录状态下解释中断。同步更新本地模拟服务的输出格式，并检查页面候选、来源显示及历史恢复。

用户授权的七个真实问题已于 0.2.7 上执行，原轮仍为三项正常返回、四项被拦截。本轮不追加计费请求；0.2.9 的改动通过离线验证，尚未获得真实服务复验结论。数据库与已保存模型配置保留。
