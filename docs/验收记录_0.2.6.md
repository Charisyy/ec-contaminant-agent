# 0.2.6 当前功能范围调整

日期：2026-10-19。

按用户决定，将生态毒性预测移出当前版本功能规划和验收范围，移除活跃待办中的相关任务及候选模型登记。README、Agent 说明和方法登记统一围绕目录、身份与结构、官能团、结构相似性与聚类、已有生态证据整理。

原程序没有已实现的毒性预测模型或页面入口，因此没有删除生态证据工具或 EPA 基准数据。后台继续只允许三个已登记流程；不接受预测流程请求。配置中的禁止预测标记保留，用于明确执行边界，不代表待开发模块。历史验收记录继续保留。

针对性验证覆盖参数边界、三个独立固定流程、组合流程共享步骤与数据库完整性、网页 API 与静态脚本，以及交付资源完整性。另检查桌面启动、固定分析和已有模型配置保留。未调用真实付费模型，未重建数据库。
