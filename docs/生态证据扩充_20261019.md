# 生态证据扩充记录

更新日期：2026-10-19；对应版本：0.2.10。

本轮在原有 1,181 条 EPA 水生生物基准之外，新增 **21,267 条实验端点记录**。证据总量为 **22,448 条**，覆盖实体由 **136 / 1,216（11.2%）** 增至 **382 / 1,216（31.4%）**，新增覆盖 246 个实体。

新增记录关联 **1,956 个 ECOTOX 参考文献编号和 1 篇直接核对原文的论文**。这不是本轮逐篇阅读了 1,957 篇论文，也不是 21,267 个独立实验或独立文献。ECOTOX 可能同时收录论文和报告；不同参考编号也可能涉及相关研究。文献级系统去重、研究质量评价尚未完成。

## 来源与核验状态

1. [EPA ECOTOX 官方数据库](https://cfpub.epa.gov/ecotox/)：使用 [2026-09-15 全量 ASCII 快照](https://gaftp.epa.gov/Ecotox/ecotox_ascii_09_15_2026.zip)，按全部目录 CAS 筛选，新增 **21,264 条** LC50、EC50、NOEC 记录。均标记 `database_curated`（数据库整理，原文待复核），不伪装成已阅读原文。
2. Brinkmann 等（2022），[原始论文，DOI 10.1021/acs.estlett.2c00050](https://doi.org/10.1021/acs.estlett.2c00050)：核对 [公开原文副本](https://www.newswise.com/pdf_docs/164582402962361_030222TiresandFish.pdf) 的方法、结果及图 1，新增 **3 条** 6PPD-醌鱼类端点，标记 `full_text_checked`。ECOTOX 本轮严格筛选未匹配到该目录 CAS 的这些记录。
3. 数据库方法核对：[Olker 等，2022，ECOTOX 方法论文](https://doi.org/10.1002/etc.5324)及[官方用户指南](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10164D9.TXT)。ECOTOX 是从原始研究整理的实验数据集合；单条结果仍须回查原文背景，数据库收录不等于研究质量已完整评价。

原有 EPA 基准仍标为官方基准汇编；不同端点各自保存，未转换为 PNEC。当前端点类型计数：`{"EC50": 3511, "LC50": 8313, "NOEC": 9443, "aquatic_benchmark": 1181}`。

## 筛选与数据边界

- 只匹配校验位有效的精确 CAS，且目录类型为单体/命名实体；不按名称模糊补齐，不将酸、盐、阴离子、异构体互相替代。100 个缺 CAS 实体不会凭名称自动导入。
- 本轮限定明确的淡水 FW、海水 SW 和无附加标记的 LC50、EC50、NOEC；保留原始 mg/L、ug/L、ng/L，不为补数量换算离子当量、制剂、饮食剂量、土壤剂量或摩尔浓度。
- 带斜杠或星号的介质/端点、复杂制剂、制剂浓度 F、离子当量、近似符号以及无法解释的单位暂缓，排除不表示数据错误。
- 浓度依据按官方编码解释：M 才明确标为实测；U/X 等原码保留，NR/NC 不推断为实测。D/T 是溶解态/总量，不能当成实测/名义浓度标记。
- 保留结果编号、试验编号、参考文献编号、题名/作者/年份/DOI、物种、生命阶段、效应/测量、观察时长与暴露时长、限定符、浓度依据、原始注释、记录摘要和快照 SHA256。原始范围字段不自动当作置信区间解释。
- 新增记录 `identity_confirmed=0`，不改变人工身份核查结论；研究端点不自动转成当地评价基准。观察时长与试验持续时间分别保存，未按某个时长阈值自行划分急慢性。
- 原来的 1,181 条基准记录、1,216 个实体、结构和人工核查记录已逐表检查保留。原 Excel 未修改。仍无导入的环境暴露浓度，未生成环境风险排名。

候选初筛共 39,029 条；后续因浓度依据待复核排除 14,408 条、制剂待复核 3,190 条、离子当量待复核 226 条、目录非单体或 CAS 校验未过 90 条。保留 21,264 条，另加 3 条原文核对记录。该统计只反映本轮选择范围，不代表 ECOTOX 或文献的全部覆盖。

## 页面与工作流

实体详情每页 40 条，可翻页并导出该实体全部证据 CSV；每行显示原文核验状态、时长、浓度依据和论文链接。单条记录可展开查看原始限定条件。

Agent 和固定分析每次只取得前 12 条预览，同时返回总量及按端点分类的计数，避免大量证据挤满模型上下文。预览按出处、年份组织，未按最低毒性值排序；分析 JSON 和问答导出只含预览，完整数据使用证据 CSV。不会让模型凭未返回的文献给出结论。未新增付费模型请求。

## 仍需补充

1. **834 个实体**尚未收录本轮适用证据；其中可能存在 CAS 缺失、特殊材料、其他介质/单位或本轮严格筛选未纳入的研究，不能断言文献中不存在。
2. 优先对研究计划里的目标物逐篇核对原文，标明试验设计、纯度、对照、统计和质量问题；公开摘要可核对的值与全文已核对值分开。
3. 近期 6PPD-醌研究线索：[Shankar 等，2025，海岸割喉鳟不同生命阶段研究](https://doi.org/10.1021/acs.est.5c03697)，[USGS 作者机构页面](https://pubs.usgs.gov/publication/70268656)。作者摘要可检索，本文全文访问本次返回 403；未将摘要数值直接加入已核对全文的数据。另需核对 [Tian 等，2022，商业标准品修订毒性值](https://doi.org/10.1021/acs.estlett.1c00910)，避免将修订前后的估计当成独立重复试验。
4. PFAS 酸/盐/阴离子、金属离子当量、制剂及带特殊标记结果须建立明确的人工审查规则后再扩大；不由 Agent 自行决定换算。
