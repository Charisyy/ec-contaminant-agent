# 官能团规则校核与边界

日期：2026-10-19。当前规则版本：1.2。当前方法为固定 SMARTS 子结构匹配，包含 17 条规则，另有芳香原子特征。

## 已完成的工作

为每条规则准备一个正例和一个反例，共 34 个；另记录 8 个边界样例，共 42 个。样例包含结构、检查目标及预期匹配次数，保存在 `validation/functional_group_cases.json`，可运行 `scripts/validate_release.py` 重复检查。测试保证实现与这些明确样例一致，不能视为官能团定义已获独立科学认证。研究者审阅状态仍为待审阅。

## 一个已修复的误分类

旧版 `[N+](=O)[O-]` 会同时命中硝基甲烷与硝酸甲酯。1.2 使用 RDKit 官方 `Functional_Group_Hierarchy.txt` 中的 Nitro 模式，要求氮与碳连接；硝酸酯及无机硝酸根不再计入本规则。硝基不会被计为胺的既有检查继续保留。

来源为 [RDKit 官方规则文件](https://github.com/rdkit/rdkit/blob/master/Data/Functional_Group_Hierarchy.txt)，本机 RDKit 2026.09.1 随附文件与其 Nitro 项相符。完整本机来源文件、原始版权和 BSD 许可保存在 `third_party/RDKit_Functional_Group_Hierarchy.txt`，其 SHA256 记录在校核用例文件中。仅采用 Nitro 项，其余项目规则没有整体替换为 RDKit 层级分类。

## 已确认、尚未扩大覆盖的边界

| 样例 | 当前结果 | 解释 |
|---|---|---|
| 磷酸三甲酯 | 磷酸酯匹配 3 次 | 一个磷中心产生多个不同原子集合匹配，不代表有三个独立磷酸官能团。 |
| 磷酸单甲酯二阴离子 | 磷酸酯匹配 0 次 | 当前模式未覆盖该电离形式；属于已知漏检。 |
| 碳酸二甲酯 | 酯匹配 2 次 | 本项目酯定义覆盖 C(=O)-O-C，两个方向均可匹配。 |
| 脲 | 酰胺匹配 2 次 | 两个 N-C(=O) 连接分别命中。 |
| 邻苯醌 | 醌片段匹配 0 次 | 当前模式只覆盖所示对苯醌型片段，未覆盖所有醌。 |
| 苯 | 芳香原子 6 个 | 此处计数为原子数，不能解释为芳香环数。 |
| 吡咯 | 胺匹配 0 次 | 当前胺规则排除芳香氮；不代表该分子不含氮。 |
| 硝酸根 | 硝基匹配 0 次 | 1.2 的 Nitro 要求与碳连接。 |

## 方法依据与待审事项

[RDKit 子结构检索文档](https://www.rdkit.org/docs/GettingStartedInPython.html#substructure-searching)说明 SMARTS 匹配会返回原子索引及不同匹配。[Daylight SMARTS 原始说明](https://www.daylight.com/dayhtml/doc/theory/theory.smarts.html)用于核对原子、连接数及递归模式语义。[RDKit 芳香性说明](https://www.rdkit.org/docs/RDKit_Book.html#aromaticity)明确芳香性由指定模型处理。[Ertl 原论文（2017）](https://doi.org/10.1186/s13321-017-0225-z)提出通过原子标记与合并识别官能团的方法；当前固定片段表没有声称复现该算法，也不能因几个样例通过就称为完整官能团识别。

仍需研究者审阅各条定义与研究用途，决定是否扩大带电形式、邻醌和芳香杂环的覆盖，以及是否按中心原子合并匹配。运行时 Agent 不修改 SMARTS、计数规则或这些科学选择。本轮仅修复有官方模式依据的硝基误分类，其余边界保留并披露。

历史数据库未重算，旧缓存与当前计算分开显示。官能团命中、匹配次数及结构相似性均不等同于毒性或环境风险。
